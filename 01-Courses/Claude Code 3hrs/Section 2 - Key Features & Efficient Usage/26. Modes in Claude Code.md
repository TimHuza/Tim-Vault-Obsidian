#claude-code 


Claude Code has a few distinct "modes" that control how much autonomy it has when editing files or running commands. Here's a breakdown:

## 1. **Normal mode** (default)

- Claude proposes edits/commands and asks for approval before each file write or potentially risky command.
- Purpose: safe default for most work — you review every change before it happens.
- How it works: each tool call (edit, bash command) triggers a permission prompt unless you've pre-approved that specific action/pattern.

## 2. **Auto-accept edits mode** (`shift+tab` to toggle)

- Claude automatically applies file edits without asking, but still may prompt for other risky operations (like bash commands) depending on config.
- Purpose: speeds up iterative coding when you trust the direction and don't want to approve every diff.
- How it works: toggled via keyboard shortcut in the REPL; edits are written directly to disk, visible in your editor/git diff in real time.

## 3. **Plan mode** (`shift+tab` twice, or the mode you currently have on)

- Claude is restricted to **read-only** operations — it can explore the codebase, read files, search, but cannot edit files or run mutating commands.
- Instead, it produces a **plan** (a proposed sequence of changes) that you review and explicitly approve before any execution happens.
- Purpose: lets you validate the _approach_ before any code is touched — useful for complex or risky changes where you want to catch a bad plan early rather than after edits are made.
- How it works: Claude works in this constrained tool set until you exit plan mode (accepting the plan), at which point it switches to normal/auto-accept mode to execute.

## 4. **Bypass permissions mode** (`--dangerously-skip-permissions` flag, sometimes called "yolo mode")

- Skips all permission prompts — edits and commands run immediately, no confirmation.
- Purpose: for sandboxed/CI environments or when you fully trust the session and want zero friction.
- How it works: launched via a CLI flag; not recommended for general interactive use since it removes your safety net.
