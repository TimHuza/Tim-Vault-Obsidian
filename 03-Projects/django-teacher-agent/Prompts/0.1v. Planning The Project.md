# Django Teacher Agent System - Project Planning Prompt

You are a senior AI architect and agent-system designer.

Your task is to help me **plan** a multi-agent AI system called **Django Teacher Agent**.

Do **not implement any code**.  
Do **not write the actual agents**.  
Focus only on **architecture, design, planning, and structure**.

The goal is to build an AI tutor that teaches Django like a professional teacher. It should help beginners understand Django concepts, write better code, debug problems, and learn secure development practices.

---

# Project Goal

Design a Django Teacher Agent that acts as the main teacher and delegates tasks to specialized sub-agents.

The system should:

- Teach Django concepts clearly.
- Explain existing code line-by-line.
- Help write Django code.
- Debug Django errors.
- Explain best practices.
- Teach Django security.
- Guide the user instead of only giving answers.
- Adapt explanations for beginners while still providing professional knowledge.

---

# Main Agent

Design the responsibilities of the main Django Teacher Agent.

The main agent should:

- Understand the user's question.
- Decide which specialized agent should handle the request.
- Combine responses from multiple agents when needed.
- Maintain teaching style and consistency.
- Track the user's learning progress.

Explain:

- What responsibilities belong to the main agent.
- What decisions it should make.
- How it communicates with sub-agents.
- How routing between agents should work.

## 1. Django Code Explanation Agent

Purpose:

Explain Django code and help users understand existing projects.

Should handle:

- Explaining views.py
- Explaining models.py
- Explaining forms.py
- Explaining serializers
- Explaining templates
- Explaining URLs
- Explaining middleware
- Explaining Django ORM queries

Examples:

"Explain this view function"

"What does this model do?"

"Why do we use this decorator?"

---

## 2. Django Concept Teacher Agent

Purpose:

Teach Django concepts from beginner to advanced level.

Should explain topics like:

- What is a model?
- What is a view?
- What is a template?
- What is csrf_token?
- What is middleware?
- What is authentication?
- What are migrations?
- What is Django ORM?
- What are QuerySets?
- What is Django architecture (MVT)?

The agent should:

- Use simple explanations.
- Use analogies.
- Provide examples.
- Connect concepts together.

---

## 3. Django Coding Assistant Agent

Purpose:

Help users write Django code.

Responsibilities:

- Generate code examples.
- Suggest improvements.
- Explain why certain approaches are used.
- Follow Django best practices.
- Help design applications.

Should help with:

- Creating apps.
- Writing models.
- Creating views.
- Creating forms.
- Creating APIs.
- Writing tests.

---

## 4. Django Debugging Agent

Purpose:

Find and fix Django errors.

Responsibilities:

- Analyze error messages.
- Explain the cause.
- Suggest fixes.
- Teach debugging techniques.

Should handle:

- Tracebacks.
- Migration errors.
- Template errors.
- Database issues.
- Import errors.
- Configuration problems.
- Deployment errors.

The agent should explain:

1. What happened.
2. Why it happened.
3. How to fix it.
4. How to prevent it.

---

## 5. Django Security Agent

Purpose:

Teach secure Django development.

Should cover:

- CSRF protection.
- XSS prevention.
- SQL injection.
- Authentication security.
- Authorization.
- Password handling.
- Secure settings.
- Environment variables.
- HTTPS.
- Django security checklist.

Responsibilities:

- Review code for security problems.
- Explain vulnerabilities.
- Suggest safer alternatives.

Suggest other useful Django teaching agents.
