
# 1. Student Event Hub ⭐⭐⭐⭐⭐ (My Favorite)

**Problem**

- Students receive many emails.
    
- Important events get buried.
    
- Students forget deadlines or don't notice clubs.
    

**Idea**  
Create one website/app that automatically organizes school events into a calendar.

Instead of searching through emails:

```
Upcoming Events

📅 Aug 30
- Volleyball Tryouts

📅 Sept 1
- First Day of School

📅 Sept 4
- Robotics Club Meeting

📅 Sept 8
- Student Council Elections
```

Possible features:

- Search events
    
- Calendar view
    
- Categories
    
- Reminders
    
- Add to Google Calendar
    
- "What's happening this week?"
    

Future ideas:

- AI summarizes long emails into one sentence.
    
- AI extracts dates automatically.

One final suggestion: if this is a portfolio project as well as a school project, consider designing it as a **modular platform**. Instead of making a single-purpose app, plan a "Student Portal" where features like Events, Homework, Clubs, Volunteer Hours, AI Summaries, and a School Map are separate modules. You can start with one module for the project, then continue adding others over time, demonstrating how the platform could grow into something genuinely useful for students and staff.
