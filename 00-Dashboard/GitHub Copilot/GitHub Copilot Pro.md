
## Best Models To Use
| Task                  | Best model from your list                 | Why                                                       |
| --------------------- | ----------------------------------------- | --------------------------------------------------------- |
| Everyday coding       | **GPT-5.6 Terra** ⭐                       | Good balance of intelligence and speed                    |
| Python development    | **GPT-5.4** or **GPT-5.6 Terra**          | Strong reasoning and code generation                      |
| Django                | **GPT-5.4** ⭐                             | Good for framework understanding, debugging, architecture |
| Explaining code       | **Claude Sonnet 5 / Claude Sonnet 4.6** ⭐ | Claude is excellent at teaching and explanations          |
| Debugging errors      | **GPT-5.4**                               | Strong reasoning through complex problems                 |
| Large refactoring     | **Claude Sonnet 5** ⭐                     | Very good at understanding many files                     |
| Planning applications | **Claude Sonnet 5** ⭐                     | Excellent system design and architecture                  |
| Quick questions       | **GPT-5.4 mini**                          | Faster and uses fewer credits                             |
| Simple autocomplete   | **MAI-Code-1-Flash / GPT-5.4 mini**       | Fast responses                                            |

### For your AI Agent projects (LangChain/LangGraph)

I would use:

1. **Claude Sonnet 5**
    - architecture
    - agent design
    - workflows
2. **GPT-5.4**
    - implementation
    - debugging
    - Python code

### Models I would not use as your main model
